## Project Overview

Sri Sai AI Tuitions is an educational tuition website focused on helping students improve understanding, confidence, and academic consistency through a structured learning experience. The site presents a parent-friendly overview of the tuition model, emphasizing personalized attention, regular practice, and progress-oriented learning support.

The current project is designed as a modern static front-end experience that communicates a professional learning brand while remaining simple to navigate on desktop and mobile devices. It highlights a one-week free trial, clear pricing plans, contact and enquiry options, and a warm, encouraging educational identity.

## Key Features

- Student-focused learning positioning and educational branding
- Parent-friendly tuition information and enquiry flow
- One-week free trial to encourage new enquiries
- Clear tuition plans and fee structure
- Weekly practice and progress-oriented messaging
- Responsive layout for desktop and mobile devices
- Simple navigation with calls to action for booking and contact
- AI-assisted learning concept integrated into the brand experience

## Greeshma AI Learning Assistant

The website introduces Greeshma AI as a friendly learning companion designed to support student confidence and learning habits. The concept is presented as an educational assistant that can help with subject-related questions, homework guidance, practice questions, exam preparation, study planning, and tuition-related enquiries.

The assistant is positioned as part of a supportive learning experience, reinforcing the idea of personalized guidance and consistent academic encouragement rather than presenting a fully autonomous system beyond the website's actual scope.

## Website UI/UX and User Experience

The interface is built around a clean, modern education landing-page design with strong visual hierarchy, clear spacing, and conversion-focused call-to-action sections. The layout is intended to help visitors quickly understand the tuition approach, pricing, and contact process without unnecessary complexity.

The experience includes:

- Clear top-level navigation for key sections
- Strong hero messaging for value and trust
- Customer-facing educational branding and emotional tone
- Mobile-friendly layout and responsive content blocks
- Distinct sections for approach, pricing, and contact
- A simple enquiry form connected through Formspree

## Before and After Development

The project reflects a clear progression from an earlier GitHub Pages version to the current Hatchable-hosted experience. The earlier version was a basic static landing page, while the current site presents a more refined educational brand with cleaner structure, clearer messaging, and stronger visual organization.

### Earlier GitHub Pages Version

- Simpler presentation and earlier visual style
- Basic static layout and less refined structure
- Limited emphasis on modern educational branding

### Current Hatchable Version

- Updated visual presentation and clearer hierarchy
- Improved content organization and simplified navigation
- Stronger student and parent communication
- Better responsive experience on smaller screens
- More polished educational branding for the tuition business
