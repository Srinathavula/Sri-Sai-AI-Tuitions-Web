## Live Website

Visit the site here: https://sri-sai-ai-tuitions.hatchable.site/

## Project Overview

Sri Sai AI Tuitions is built to present a professional, parent-friendly online presence for a tuition business focused on personalized learning, weekly practice, and continuous academic support. The project combines a strong visual identity, clear calls to action, transparent fee plans, and a simple enrollment flow to help parents understand the value of one-to-one tuition.

This repository contains the source for the public-facing website and the project documentation for the brand, website structure, and service positioning.

## Key Features

- Personalized learning experience for students
- AI-assisted learning positioning and modern education branding
- One-week free trial emphasis for first-time parents
- Clear fee and plan structure
- Weekly practice and progress tracking messaging
- Responsive design for desktop and mobile devices
- Parent-friendly booking and contact flow
- Clean landing page tailored for educational services

## Greeshma AI Assistant

The idea behind the website is supported by a friendly, approachable AI learning assistant concept called Greeshma, designed to reinforce the brand promise of guided, student-focused learning. The current experience communicates a digital tutoring environment that is:

- supportive and encouraging
- customized for each learner
- built around consistency and confidence
- designed to reduce anxiety and improve understanding

This assistant persona helps communicate how the tuition offering blends technology with human mentorship and structured academic coaching.

## Before and After Improvement

The redesign focuses on making the website feel more credible, polished, and recruiter-friendly by improving:

- conversion-focused calls to action

The project modernizes the earlier static version into a more refined learning-brand experience that better reflects a real-world educational business.
